LOGO
  logo/okynus-mark-*       Primary mark. Default choice for most placements.
  logo/okynus-wordmark-*   Horizontal wordmark for headers, documents, tight spaces.
  logo/okynus-icon-*       The mark without the word, for small square placements.
  logo/okynus-appmark-*    Tri-color fingerprint O: app icons, favicons, avatars. No background tile.
  "on-dark" = white linework for dark backgrounds; "on-light" = Void linework.
  Use the SVGs wherever possible. Never redraw, recolor, stretch, rotate, outline,
  add effects to, or re-type the logo. Clear space: x = the diameter of one node on the primary mark and icon, the fingerprint O on the wordmark, or the ring thickness on the app mark, on every side.

COLOR

  Lock Green #A5D76E   secondary
  Data Coral #FF6464   accent

  For text on white, use cyan-700 #007C9C, green-700 #4F7A26, coral-600 #E51D1D.

TYPE
